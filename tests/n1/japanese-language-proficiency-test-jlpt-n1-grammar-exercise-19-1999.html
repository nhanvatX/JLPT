Answer Key:

Question 1: 3 ( 彼女は海外留学のつらい経験を並べあげ、あげくの果てには学業をあきらめて帰国したいと言って泣き出すしまつだった。)
Question 2: 2 ( わたしが小学校に入るか入らないかのころ、父とどこか大きな川へ釣りに行った記憶がある。)
Question 3: 1 ( 寮はうるさくて勉強できないと思いひとり暮らしを始めたが、勉強するどころか、さびしくて電話ばかりかけている。)
Question 4: 2 ( 創業３３年、研究に研究をかさね、ついに行き着いた味！！自信を持ってお勧めする一品。)
Question 5: 4 ( 部下「課長、W社から納期を一週間早めてほしいという連絡があったんですが。」課長「え、納期の日程を設定したのはあっちだろう。それを、納期まで2週間の今になって、早めろと言うなんて勝手過ぎる。どういうことなんだ。」)
Question 6: 1 ( X交通のバス路線が一部廃止される問題で、会社側から地域住民に対し、路線を廃止するに至った経緯及び今後の対応について、説明がなされた。)
Question 7: 3 ( 景気は回復に向かっているように見えたが厳しい状況が続くとのことだ。)
Question 8: 4 ( 彼らはいかなる困難をものともせずにひたすら前に進んでいる。)
Question 9: 2 ( たんぱく質は体の組織を作る重要な成分ですが、多くとったからといってより丈夫になるかというとそういうものでもなく、とりすぎは逆に健康に悪影響を及ぼすことがあります。)
Question 10: 2 ( 家族みんなが一緒に暮らすことさえできればそれで幸せだと思う。)

New words:

あげくの果て (agekunohate): finally; in the end; on top of all that

学業 (gakugyou): studies; schoolwork; classwork

帰国 (kikoku): return to one’s country

記憶 (kioku): memory

寮 (ryou): dormitory

創業 (sougyou): establishment

行き着く (yukitsuku): to arrive at; to end up

一品 (ippin): item; article; dish

納期 (nouki): time for payment; appointed day of delivery

早める (hayameru): to advance; to hasten; to speed up

日程 (nittei): schedule; program

設定 (settei): establishment; options setting

勝手 (katte): one’s own convenience; one’s way; selfish

交通 (koutsuu): traffic; transportation

路線 (rosen): route; line

廃止 (haishi): abolition; repeal

住民 (juumin): citizens; inhabitants

経緯 (ikisatsu): details; particulars

たんぱく質 (tanpakushitsu): protein

組織 (soshiki): organization

成分 (seibun): ingredient; component; composition
