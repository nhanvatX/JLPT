JLPT N1 – Kanji Exercise 05

March 14, 2015   JLPT N1 Kanji test

彼は自分よりも相手を思いやることを知り、強いリーダーシップと強烈な愛国心の持ち主でもあります。

1. 強烈
こうれつ
こうやす
きょうれつ
きょうやす

１０年もすれば船が安全に北極海を航行できる日が年間１１０日に達するみこみだという。これは人類の歴史では前例のない事態だ。

2. みこみ
診込み
観込み
視込み
見込み

この地域全体が最強の国家群さえ拘束する国際規範を受け入れることになるのか？

3. 規範
きはん
みはん
みばん
きぱん

彼はとてもロマンチックで、愛する女性のためにはさいぜんを尽くす、完璧な男です。

4. さいぜん
最羊
最菩
最善
最美

山田が自殺の前に撮ったその不可解な映像には、全身が凍りつく思いだ。

5. 映像

えぞう
えいそう
えいぞう

北極の氷床の下とその海域には、世界全体の石油・天然ガスの未確認まいぞう量の２２％が眠っている可能性がある。

6. まいぞう
理臓
理蔵
埋蔵
埋臓

一番と二番では中村栄助の主張が認められ、無罪判決を勝ち取った。だが、最高裁が判決を放棄、地裁へと差し戻す。

7. 放棄
はなき
はなか
ほうき
ほうか

優秀な社員の流出を止めなければならないと考え、ストックオプションの価格かいていも計画した。

8. かいてい
攻定
改定
放定
故定

貨幣の偽造は、経済的取引の信用を損なうおそれがあるため、重大な犯罪として厳しく処罰される。

9. 貨幣
しへい
かへい

10. 偽造

11. 損なう

工場用地を整備して、地元の産業の振興をはかる。

12. 振興
しんこう

しきょう

Answer Key:

Question 1: 3 (強烈 => きょうれつ)
Question 2: 4 (みこみ => 見込み)
Question 3: 1 (規範 => きはん)
Question 4: 3 (さいぜん => 最善)
Question 5: 4 (映像 => えいぞう)
Question 6: 3 (まいぞう => 埋蔵)
Question 7: 3 (放棄 => ほうき)
Question 8: 2 (かいてい => 改定)
Question 9: 2 (貨幣 => かへい)
Question 10: 4 (偽造 => ぎぞう)
Question 11: 1 (損なう => そこなう)
Question 12: 1 (振興 => しんこう)

New words:

思いやる (omoiyaru): to be considerate, to sympathize with

リーダーシップ: leadership

強烈: strong, intense, severe

愛国心 (aikokushin): patriotic feelings, patriotism

持ち主 (mochinushi): owner

北極海 (hokkyokukai): Arctic Ocean

航行 (koukou): cruise, navigation, sailing

達する (tassuru): to reach, to get to

みこみ: forecast, prospects, expectation, hope

人類 (jinrui): mankind, humanity

前例 (zenrei): precedent

規範: model, standard, pattern

ロマンチック: romantic

さいぜん: the very best

尽くす (tsukusu): to exhaust, to run out, to devote

不可解 (fukakai): mystery, baffling, incomprehensible

映像 (eizou): image, picture, clip

凍りつく (kooritsuku): to freeze to, to be frozen to

北極 (hokkyoku): North Pole, the Arctic

氷床 (hyoushou): ice sheet

海域 (kaiiki): area of ocean

未確認 (mikakunin): unconfirmed, unidentified

まいぞう: buried property, treasure trove

無罪判決 (muzai hanketsu): an innocent verdict

勝ち取る (kachitoru): to exert oneself and win, to gain (victory)

最高裁 (saikousai): Supreme Court

判決 (hanketsu): judicial decision, judgement

放棄: abandonment, renunciation

地裁 (chisai): district court

差し戻す (sashimodosu): to send back, to refer back

流出 (ryuushutsu): discharge, outward flow

ストックオプション: stock option

かいてい: reform

貨幣: money, currency

偽造: forgery, falsification

取引 (torihiki): transactions, dealings

信用 (shin’you): confidence, dependence

損なう: to harm, to hurt

処罰 (shobatsu): punishment

用地 (youchi): site

整備 (seibi): maintenance, servicing, outfitting

地元 (jimoto): home area, home town, local

産業 (sangyou): industry

振興: promotion, encouragement
