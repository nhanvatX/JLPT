JLPT N1 – Kanji Exercise 04

March 14, 2015   JLPT N1 Kanji test

このことは、新政府が改革に真剣であることを示す説得力ある証拠となった。

1. 改革
かいかく
かいかわ
かいこう
かいげき

「人に喜んでもらう」ための、別の仕事にちょうせんしてもいいんじゃないかと思うようになったんです。

2. ちょうせん
挑禅
兆禅
兆戦
挑戦

膝を折ってうずくまり、襲撃されたと一瞬思った。

3. 襲撃
こうげき
しょうげき
しゅうげき
とうげき

納得できないミナコのとまどいを察して、タクミはしんぼう強く微笑んでいる。

4. しんぼう
辛包
辛抱
幸抱
幸包

Googleの検索の精度は日々進化しており、ユーザーに害をなす粗悪なサイトは結果から除外されやすくなっている。

5. 除外
よがい
しがい
じょがい
じょうがい

今回は、民衆からのはんのうこそが驚くものだった。

6. はんのう
仮応
反応
坂応
返応

彼は明日の早朝から大阪で開催される業界団体の大会に出発してしまい、来週の金曜日まであえなくなる。

7. 開催
かいすい
かいしん
かいそく
かいさい

これはわたしだけが主張しているがくせつじゃない。昔からある考えなんだよ。

8. がくせつ
学設
学説
学訳
学語

目の前には、日々本を読み、音楽を聞き、夢を見てすごす長閑な暮らしがどこまでもつづいていた。

9. 長閑
たけか
ながか
のどか
ちょうか

二つの戦争を終結に向かわせ、新たな脅威にたいおうし、新しい機会をつかむ必要がある。

10. たいおう
対応
効応
態応
隊応

事態をこれ以上悪化させないためには、軽率な行動を避けることはもちろん、相互の不信感を取り除く努力をする必要があろう。

11. 軽率
けいりつ
けいそつ
かいりつ
かいそつ

12. 取り除く
とりさく
とりほどく
とりのぞく
とりまく

Answer Key:

Question 1: 1 (改革 => かいかく)
Question 2: 4 (ちょうせん => 挑戦)
Question 3: 3 (襲撃 => しゅうげき)
Question 4: 2 (しんぼう => 辛抱)
Question 5: 3 (除外 => じょがい)
Question 6: 2 (はんのう => 反応)
Question 7: 4 (開催 => かいさい)
Question 8: 2 (がくせつ => 学説)
Question 9: 3 (長閑 => のどか)
Question 10: 1 (たいおう => 対応)
Question 11: 2 (軽率 => けいそつ)
Question 12: 3 (取り除く => とりのぞく)

New words:

真剣 (shinken): seriousness, earnestness

説得力 (settokuryoku): persuasive power

ちょうせん: challenge, defiance

膝 (hiza): knee, lap

うずくまる: to crouch, to squat, to cower

襲撃: attack, charge, raid

納得 (nattoku): understanding, comprehension, grasp

とまどい: being at sea, losing one’s bearings, confusion

察する (sassuru): to guess, to presume

しんぼう: patience, endurance

微笑む (hohoemu): to smile

検索 (kensaku): looking up, searching for

精度 (seido): precision, accuracy

進化 (shinka): evolution, progress

ユーザー: user

害 (gai): injury, harm, evil influence

粗悪 (soaku): coarse, crude, inferior

除外: exception, exclusion

民衆 (minshuu): people, populace, masses

はんのう: reaction, response

早朝 (souchou): early morning

開催 (kaisai): holding a meeting, open an exhibition

業界団体 (gyoukaidantai): industry group

大会 (taikai): convention, tournament

主張 (shuchou): claim, insistence, emphasis

がくせつ: theory

長閑: tranquil, calm, quiet

終結 (shuuketsu): end, close

脅威 (kyoui): threat, menace

たいおう: coping with, dealing with

事態 (jitai): situation, (present) state of affairs

軽率: rash, thoughtless, careless

相互 (sougo): mutual, reciprocal

不信感 (fushinkan): distrust, suspicion

取り除く: to remove, to take away
