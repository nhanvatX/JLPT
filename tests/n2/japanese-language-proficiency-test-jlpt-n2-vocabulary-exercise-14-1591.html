JLPT N2 – Vocabulary Exercise 14

June 26, 2015   JLPT N2 vocabulary test

1. 人間はしょせん欲の _______　で、自己中心的なものである。
あつまり
かみなり
かたまり
つながり

2. 「すぐ失礼しますので、 _______　。」
おかまいなく
ご遠慮なく
ごめんください
お大事に

3. 今回の大臣の訪問は _______　公式に行われた。
不

未
無
非

4. 西洋占星術で今年の運勢を _______　みた。
うらやんで

うらぎって
うらなって
うらがえして

5. ストレスを _______　するために、何かしていますか。
解消
削除
減量
停止

「_______ 」の言葉に意味が最も近いものを、１・２・３・４から一つ選びなさい。

6. 引っ越しの荷物は「大半」片付いた。
全面
大通り
大抵
何分

7. この作業は「慎重に」やってください。
急いで
絶対忘れずに
静かに
十分注意して

8. 人が前に立つと、ドアが「ひとりでに」開く。
自然に
突然
偶然
必然に

9. 公演の「スケジュール」はもう決まった。
予約
日程
計算
企画

10. 人気商品で、「たちまち」売切れてしまう。
しばしば
ゆっくり
すぐに
さらに

Answer Key:

Question 1: 3 ( 人間はしょせん欲のかたまりで、自己中心的なものである。)
Question 2: 1 ( 「すぐ失礼しますので、おかまいなく。」)
Question 3: 4 ( 今回の大臣の訪問は非公式に行われた。)
Question 4: 3 ( 西洋占星術で今年の運勢をうらなってみた。)
Question 5: 1 ( ストレスを解消するために、何かしていますか。)
Question 6: 3 ( 大半 => 大抵 )
Question 7: 4 ( 慎重に => 十分注意して )
Question 8: 1 ( ひとりでに => 自然に )
Question 9: 2 ( スケジュール => 日程 )
Question 10: 3 ( たちまち => すぐに )

New words:

自己中心的 (jikochuushinteki): egoistic; self-centered; selfish

集まり (atsumari): gathering; meeting; assembly

雷 (kaminari): lightning; thunder

塊 (katamari): lump; mass; bundle

繋がり (tsunagari): connection; link; relationship

おかまいなく: please don’t fuss over me

大臣 (daijin): cabinet minister

訪問 (houmon): call; visit

非公式 (hikoushiki): informal; unofficial

西洋 (seiyou): the West; Western countries

占星術 (senseijutsu): astrology

運勢 (unsei): fortune; luck

うらやむ: to envy

裏切る (uragiru): to betray; to turn traitor to; to double-cross

占う (uranau): to tell someone’s fortune; to forecast

裏返す (uragaesu): to turn inside out; to turn the other way

解消 (kaishou): cancellation; liquidation; resolution; reduction (e.g. of stress)

削除 (sakujo): deletion; elimination; erasure

減量 (genryou): loss in quantity; reducing quantity

停止 (teishi): suspension; interruption; stoppage

引っ越し (hikkoshi): moving; changing residence

大半 (taihan): majority; more than half

全面 (zenmen): whole surface; entire

大通り (oodoori): main street

大抵 (taitei): mostly; generally; most

何分 (nanibun): some; (a) little

作業 (sagyou): work; operation; manufacturing

慎重 (shinchou): careful; cautious; prudent

偶然 (guuzen): coincidence; chance; accident; by chance

必然 (hitsuzen): inevitable; necessary

公演 (kouen): public performance

スケジュール: schedule

予約 (yoyaku): reservation; appointment; booking; advance order

日程 (nittei): schedule; program

計算 (keisan): calculation; reckoning

企画 (kikaku): planning; project; plan

人気 (ninki): popularity

たちまち: in an instant; in a moment

売り切れる (urikireru): to be sold out

しばしば: often; again and again

ゆっくり: slowly; at ease
