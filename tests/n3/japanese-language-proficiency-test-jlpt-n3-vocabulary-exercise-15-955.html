JLPT N3 – Vocabulary Exercise 15

April 28, 2015   JLPT N3 vocabulary test

1. 店で _______ をもらってきた。
カタログ
オーダー
レシート
セール

2. 田中さんの服装はとても上品な _______ がする。
関心
気分
考え
感じ

3. 森選手は、全国で一位になることを _______ にしてがんばっている。
指定

満点
一流
目標

4. テストを始めますから、辞書をかばんの中に _______ ください。
ためって

とじて
しまって
たたんで

5. 日本の若者の _______ のファッションを知りたい。
最大
最新
最中
最多

6. いらない新聞や雑誌を重ねて、ひもで _______ 捨てた。
しばって
かこんで
しめて
あんで

7. 急に用事ができたので、レストランの予約を _______ した。
チェックアウト

カット
キャンセル
オーバー

8. 私の部屋は東 _______ だ。
沿い
向き
込み
建て

9. 昨日映画を見たとき、_______ して泣いてしまった。
歓迎
応援
期待
感動

10. 急いでいたので、_______ 違うバスに乗ってしまった。
ぴったり

ぐっすり
うっかり
がっかり

Answer Key:

Question 1: 1 ( 店でカタログをもらった。)
Question 2: 4 ( 田中さんの服装はとても上品な感じがする。)
Question 3: 4 ( 森選手は、全国で一位になることを目標にしてがんばっている。)
Question 4: 3 ( テストを始めますから、辞書をかばんの中にしまってください。)
Question 5: 2 ( 日本の若者の最新のファッションを知りたい。)
Question 6: 1 ( いらない新聞や雑誌を重ねて、ひもでしばって捨てた。)
Question 7: 3 ( 急に用事ができたので、レストランの予約をキャンセルした。)
Question 8: 2 ( 私の部屋は東向きだ。)
Question 9: 4 ( 昨日映画を見たとき、感動して泣いてしまった。)
Question 10: 3 ( 急いでいたので、うっかり違うバスに乗ってしまった。)
