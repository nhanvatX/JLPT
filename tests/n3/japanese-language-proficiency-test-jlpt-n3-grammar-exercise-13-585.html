Answer Key:

Question 1: 4 ( ３０歳というのは多くの人にとって人生の節目である。)
Question 2: 3 ( 子供の頃、よく祖母に「男らしい男になりなさい」と言われた。)
Question 3: 1 ( 木村さんに招待状を書いて、日曜のディナーにお招きし、直接お礼を申し上げられるようにしてください。)
Question 4: 2 ( 母親　「今、お菓子を買った子がタケルくん？」子供　「ちがうよ。あそこで泣いて、お菓子を欲しがっている子だよ。」)
Question 5: 3 ( これが嘘なら地獄に落ちてもかまわない。彼は本当に墓場に行きかけています。そしてあなたの他には誰も彼を救うことはできないのです！)
Question 6: 1 ( 最近発売されている液晶テレビは薄いうえに、高品質だ。)
Question 7: 3 ( 別に隠すつもりはありませんが、いまこの忙しい捜査の最中に、ながながと込み入った説明をしてはいられませんからね。)
Question 8: 2 ( この子は、もっとも簡単な質問にも答えられそうもない。)
Question 9: 1 ( 真珠を金庫へしまってくれたまえ。そしてついでに偽造事件の書類を出してくれたまえ。)
Question 10: 2 ( 田中は上司としても人間としてもモデルになるような人物ではない。わかりやすくて皆がまねしたいと思うような人物でもない。)
