JLPT N3 – Vocabulary Exercise 21

April 28, 2015   JLPT N3 vocabulary test

1. 彼は私たちを _______ んだと思うわ。
おこってる
さぼってる
かけてる
さけてる

2. 君は今夜見せたよりはましな _______ を発揮した。
才能
可能
本能
機能

3. わたしは _______ にして優秀なる頭脳に恵まれている。
直

甘い
幸い
辛い

4. 姉の結婚祝いに写真の _______ をプレゼントしようと思ってる。
カメラ

インク
アルバム
アウト

5. 彼はお父さんについて話を聞くかけがえのない機会を _______ 失ったことを悔やんだ。
えいえんに
ちなみに
まことに
そばに

6. 掃除をするので、この _______ に水を入れてきてください。
ロッカー
バケツ
ブラシ
タオル

7. お母さんはお金がなくなったことに、いつ _______ だろうか？
気付く

気に入る
気にする
気をつける

8. _______ の後、学生たちは教室に戻ってきた。
作家
現状
休憩
強調

9. _______ 、こんどこそ就寝の時間じゃ。
また
さて
でも
それは

10. 彼は新しい楽観 _______ に目覚めたかのようだった。
喧嘩
結果
議論
主義

Answer Key:

Question 1: 4 ( 彼は私たちをさけてるんだと思うわ。)
Question 2: 1 ( 君は今夜見せたよりはましな才能を発揮した。)
Question 3: 3 ( わたしは幸いにして優秀なる頭脳に恵まれている。)
Question 4: 3 ( 姉の結婚祝いに写真のアルバムをプレゼントしようと思ってる。)
Question 5: 1 ( 彼はお父さんについて話を聞くかけがえのない機会をえいえんに失ったことを悔やんだ。)
Question 6: 2 ( 掃除をするので、このバケツに水を入れてきてください。)
Question 7: 1 ( お母さんはお金がなくなったことに、いつ気付くだろうか？)
Question 8: 3 ( 休憩の後、学生たちは教室に戻ってきた。)
Question 9: 2 ( さて、こんどこそ就寝の時間じゃ。)
Question 10: 4 ( 彼は新しい楽観主義に目覚めたかのようだった。)
