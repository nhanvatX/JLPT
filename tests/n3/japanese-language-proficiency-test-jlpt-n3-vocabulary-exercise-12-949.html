JLPT N3 – Vocabulary Exercise 12

April 28, 2015   JLPT N3 vocabulary test

1. 全員が自分の意見を _______ したので、会議がなかなか終わらなかった。
命令
返信
主張
注文

2. 何度も断っているのに、彼に _______ 頼まれて困っています。
しつこく
きびしく
こまかく
くわしく

3. この商品は毎日1000個 _______ 売れるらしい。
前後
上下
大小
多少

4. いくら探しても、手袋が _______ しか見つからない。
半々
片方
反対
部分

5. 今度の試合はみんなで力を _______ 頑張ろう。
かさねて
あわせて
くわえて
ふやして

次の言葉の使い方として最もよいものを、１・２・３・４から一つえらびなさい。

6. そろそろ
もう１０分以上待っているのに、バスがそろそろ来ない。
最近洗濯機の調子がよくなかったが、昨日そろそろ壊れた。
以前から探していた本が、そろそろ見つかった。
仕事が残っているけど、そろそろ１２時なので昼休みにしよう。

7. 自慢
彼女は今度のコンサートで優勝する自慢がある。
彼はゲームで負けたことがないのを自慢している。
怒りたいのを自慢して、相手の話を最後まで聞いた。
自分にどうしても自慢が持てなくて困っている。

8. 指示
「この書類、３０部コピーしておいて」と秘書に指示した。
「この作文を見ていただけませんか」と先生に指示した。
「あした映画を見に行こうよ」と友達に指示した。
「トイレはどこにありますか」と店員に指示した。

9. 報告
若者向けの新商品をテレビで報告する。
医者は彼にたばこをやめるようにと報告した。
秘書に11時までに書類を作るように報告した。
事故について詳しく警察に報告した。

10. 見物
先生の家を見物する時、手土産は何がいい？
洋服が似合うかどうか、着て見物してみた。
一日で京都を見物することはできない。
最近、公衆電話を見物しなくなった。

Answer Key:

Question 1: 3 ( 全員が自分の意見を主張したので、会議がなかなか終わらなかった。)
Question 2: 1 ( 何度も断っているのに、彼にしつこく頼まれて困っています。)
Question 3: 1 ( この商品は毎日1000個前後売れるらしい。)
Question 4: 2 ( いくら探しても、手袋が片方しか見つからない。)
Question 5: 2 ( 今度の試合はみんなで力をあわせて頑張ろう。)
Question 6: 4 ( そろそろ => 仕事が残っているけど、そろそろ１２時なので昼休みにしよう。)
Question 7: 2 ( 自慢 => 彼はゲームで負けたことがないのを自慢している。)
Question 8: 1 ( 指示 => 「この書類、３０部コピーしておいて」と秘書に指示した。)
Question 9: 4 ( 報告 => 事故について詳しく警察に報告した。)
Question 10: 3 ( 見物 => 一日で京都を見物することはできない。)
