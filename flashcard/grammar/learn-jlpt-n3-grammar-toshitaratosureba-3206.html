Learn JLPT N3 Grammar: としたら/とすれば (to shitara/to sureba)

July 9, 2015   Learn Japanese N3 Grammar


[Ảnh: Japanese Grammar: としたら/とすれば (to shitara/to sureba)]

Meaning: if it were the case that…; if we assume…

Formation:

Verb-casual + としたら/とすれば/とすると
いadj + としたら/とすれば/とすると
なadj + だとしたら/とすれば/とすると
Noun + だとしたら/とすれば/とすると
