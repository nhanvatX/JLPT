Learn JLPT N2 Grammar: にすぎない (ni suginai)

August 12, 2015   Learn Japanese N2 Grammar

[Ảnh: Japanese Grammar: に過ぎない (ni suginai)]

Meaning: no more than; just; merely; only

Please note that に過ぎない is not usually used with adjectives.

Formation:

Verb-casual + に過ぎない
Noun + に過ぎない
いadj + に過ぎない
なadj + であるに過ぎない
