Learn JLPT N1 Grammar: (よ)うものなら (you mono nara)

October 2, 2015   Learn Japanese N1 Grammar


Meaning: if one chooses to; if one happens to

Formation:

Verb-volitional form + ものなら

JLPT level: N1 (一級の文法)

Download JTest4You’s N1 grammar ebook (1,640 pages)

もし逃亡しようものならたちまち捕らえられ、銃殺されるだろう。
If I try to escape, I’ll probably be captured and shot.
moshi toubou shiyou mono nara tachimachi toraerare, juusatsu sareru darou.
