Learn JLPT N3 Grammar: さえ ~ ば (sae ~ ba)

June 28, 2015   Learn Japanese N3 Grammar


[Ảnh: Japanese Grammar: さえ ~ ば (sae ~ ba)]

Meaning: if only ~ then; as long as; the only thing ~ need is

Formation:

Noun + さえ + Verb-ばform
Verb-ますstem + さえすれば
Verb-てform + さえいれば
