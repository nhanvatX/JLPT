Learn JLPT N3 Grammar: べつに～ない (betsuni~nai)

July 9, 2015   Learn Japanese N3 Grammar


[Ảnh: Learn JLPT N3 Grammar: べつに～ない (betsuni~nai)]

Meaning: not really, not particularly

Formation:

別に + Verb-ないform
別に + Noun + ではない
別に + いadj (remove い) + くない
別に + なadj + ではない
